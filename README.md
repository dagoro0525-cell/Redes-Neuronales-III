# Redes Neuronales III

## Descripción del proyecto

Implementación de técnicas de optimización y regularización en redes neuronales utilizando TensorFlow y Keras. El proyecto aborda el entrenamiento, la evaluación y la comparación de modelos de clasificación de imágenes.

## Objetivo

Analizar el comportamiento de una red neuronal mediante una línea base y la aplicación de técnicas de optimización de hiperparámetros y regularización, evaluando su desempeño con métricas de clasificación.

## Estructura del repositorio

- **01_Datos_Baseline_Keras.ipynb:** implementación del modelo base y preparación de los datos.
- **02_Optimizacion_Hiperparametros.ipynb:** experimentos de optimización de hiperparámetros.
- **03_Regularización.ipynb:** implementación y evaluación de técnicas de regularización.

## Tecnologías utilizadas

- Python
- TensorFlow
- Keras
- Google Colab
- NumPy
- Matplotlib
- Scikit-learn

## Evaluación del modelo

El desempeño de los modelos se analiza mediante métricas como exactitud (*accuracy*), pérdida (*loss*), precisión, recall, F1-score y matriz de confusión.

Los resultados específicos de cada experimento se documentan en los notebooks correspondientes.

## Ejecución

Los notebooks pueden abrirse y ejecutarse en Google Colab. Para reproducir los experimentos, se deben ejecutar las celdas en el orden establecido y verificar las dependencias requeridas.
